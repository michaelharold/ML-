# Basic ML Training

A collection of Jupyter notebooks documenting my hands-on learning journey in Machine Learning and Deep Learning. This repo serves as a personal reference for experiments, implementations, and notes as I build up my ML skills - and as an organized resource for anyone learning the same topics.

## Notebooks

| Notebook | Topic |
|---|---|
| `CIFAR_10_CNN_CV.ipynb` | Convolutional Neural Network for image classification on the CIFAR-10 dataset (computer vision fundamentals: convolutions, pooling, training/evaluation) |
| `RNNXLSTMXGRU_Understanding_.ipynb` | Understanding recurrent architectures - RNN vs LSTM vs GRU - and how they handle sequential data |

## Getting Started

Open the notebooks directly in [Google Colab](https://colab.research.google.com/) (recommended, free GPU) or run locally:

```bash
pip install jupyter tensorflow numpy matplotlib
jupyter notebook
```
